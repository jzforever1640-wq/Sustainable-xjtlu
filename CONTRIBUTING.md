# Contributing to Sustainable XJTLU

Thank you for helping build Sustainable XJTLU.

## Working together

1. Create a branch from `main` using a short descriptive name, such as `feature/activity-filters`.
2. Keep each pull request focused on one change.
3. Run `pnpm build` before opening a pull request.
4. Update `public/data/content.json` for content changes; components should continue to load content through the mock API.
5. Request a review before merging. Do not push directly to `main`.

## Design principles

- Preserve the accessible, academic visual style and responsive behaviour.
- Use semantic HTML, descriptive labels and keyboard-accessible controls.
- Keep visible content data-driven rather than embedding it in components.
